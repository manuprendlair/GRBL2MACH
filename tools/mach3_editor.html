Mach3 profile editor

No profile open

Open a Mach3 profile (the .xml file in Mach3's folder, e.g. C:\Mach3\Mach3Mill.xml)

Drop it here or use Open…. The file is read and written in your browser only.

Saving replaces only the values you changed: Mach3 can still read the file. Keep the original as a backup.

Chrome and Edge save where you choose, starting in the folder of the opened file; Firefox saves to your Downloads folder.

Changed values are highlighted (↺ puts one back); the Changes tab lists them all. Ctrl+S saves.
